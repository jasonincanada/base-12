# Radix XII — Base-12 Slide Rule

An interactive SVG slide rule for dozenal arithmetic, styled after classic engraved celluloid instruments. It includes K, A, B, CI, C, D, and L scales. K is the three-cycle cube scale, CI is the reversed reciprocal (`1/x`) scale, and L is a linear scale for base-12 logarithms.

## Using it

1. Drag the centre slide until the C-scale index (`1`) sits above the first factor on D.
2. Drag the glass cursor to the second factor on C.
3. Read the product beneath the hairline on D.

The readout beneath the instrument shows all three values in dozenal notation. `X` is dek, `E` is el, and `10` is twelve.

The mouse wheel, arrow keys, and fine-adjustment buttons move the slide one SVG unit at a time. Hold Shift while pressing an arrow key to move the cursor. Double-click the instrument or press Home while it is focused to reset it.

Everything—including the scales, ticks, textures, hardware, slide, and cursor—is rendered as responsive SVG with no external assets or dependencies.

Use the `?` button in the upper-right corner for a concise explanation of every scale.
